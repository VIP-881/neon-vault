NEO-SHANGHAI // NIGHT CITY LICENCE 88-09

你是一名接入财团数据金库的夜行者。五列加密转轴在你面前展开，芯片、骰子、鬼面、武士刀与骷髅在扫描线下闪烁。每次旋转，都是对城市防火墙的一次试探。

这是一款完全运行在浏览器里的 HTML5 Canvas 老虎机：没有下载、没有注册、没有远程游戏服务器。画面由 Canvas 实时绘制，音效由 Web Audio 现场合成，随机结果使用浏览器的安全随机数生成。你的虚拟筹码与偏好只留在本机。

我们保留了传统老虎机清晰的左侧起算、逐线结算规则，同时用 5×3 布局、10 条固定赔付线、免费旋转与 Turbo 模式，把一局游戏压缩成几十秒的高密度霓虹体验。它适合想找一款即开即玩的网页游戏、又不愿接触真钱投注的人。

结算规则

  • 所有普通符号仅从最左列向右连续结算，至少 3 连。
  • 每条赔付线单独结算，同一条线只支付最高组合。
  • WILD 可以出现在任意位置，并替代普通符号；若整条线均为 WILD，按 WILD 赔付。
  • SCATTER 不要求在赔付线上，任意位置累计 3 个以上即可触发。
  • 若线首为 WILD，则由该线上第一个非 WILD 符号决定赔付类型；遇到 SCATTER 时该线中断。

  • 所有金额按整数虚拟筹码四舍五入；不涉及真实货币。

也没有真钱。

这首先是一款浏览器游戏，其次才是一台老虎机。我们希望规则、随机性和数据边界都足够清楚。

  • 01结果在旋转开始时一次性生成，动画不会改变结果。

  • 04金额与偏好仅保存在当前浏览器的 localStorage，可随时重置。

A // RNG

浏览器级随机

每个转轴单元的符号通过加权表与安全随机数选择。最终网格在动画开始前确定，停止顺序只影响观看节奏。

B // RTP

97.2% 模拟返还率

返奖率是数百万次旋转的数学期望，不是“投入 100 必回 97.2”的承诺。高波动意味着空转与大奖都更常见。

// SYSTEM QUERIES

常见问题

关于免费旋转、虚拟筹码、存档与可访问性的简短答案，适合快速浏览或引用。

NEON VAULT 是免费游戏吗？

是的。游戏完全在浏览器本地运行，无需下载、注册或付费。每位新玩家从 5,000 个虚拟筹码开始，筹码没有现金价值，也不能充值或兑换。

如何触发免费旋转？

任意位置出现 3、4 或 5 个及以上 SCATTER 时，分别获得 8、12 或 20 次免费旋转，同时按 2×、5×、20× 总投注结算 SCATTER 奖励。免费旋转期间所有中奖乘以 2，再次出现 3 个以上 SCATTER 会额外增加 2、4 或 8 次旋转。

游戏涉及真钱吗？

不涉及。NEON VAULT 是仅使用虚拟筹码的娱乐型 H5 游戏，不提供真钱投注、充值、提现或任何形式的现金奖励。

手机或平板可以玩吗？

可以。游戏采用响应式布局，支持 iOS、Android、Windows 与 macOS 上的现代浏览器。所有操作按钮均支持触屏，不需要下载应用。

游戏进度保存在哪里？

虚拟筹码、投注档位、音效与 Turbo 偏好保存在当前浏览器的 localStorage 中，不会上传到服务器。清除浏览器站点数据或点击游戏面板中的 RESET 即可重置进度。

RTP 97.2% 是否保证赢利？

不保证。RTP 是长期模拟的平均返还比例，不代表任何一局或一次会话的结果。游戏具有较高波动性，短期余额可能明显低于或高于初始值。
